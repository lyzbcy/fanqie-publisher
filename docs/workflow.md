# 长篇发布工作流

“今天更新”的完整自主续写、校对、顺序发布与交接标准见[references/daily-update.md](references/daily-update.md)。已有作者授权时由Agent完成发布，无需每章重新申请许可。每日首次使用先执行[静默更新检查](references/self-update.md)。

1. 在番茄后台登录并创建长篇作品草稿。
2. 核对作品名、频道、分类、标签、简介、封面和权利声明，取得 `book_id`。
3. 用 `prepare-novel.js` 生成独立章节和 `manifest.json`。
4. 对当次待发章节逐一执行 `--dry-run`；任何一章失败都不进入发布。
5. 配置 `book_id`，先对第1章执行 `--prepare-only`，核对确认页截图。
6. 作者已授权发布时，对第1章执行 `--publish`；尚未授权则停在准备阶段。
7. 根据发布前截图和后台章节页，核对章号、标题、全文首尾、字数、段落间距、AI声明、定时时间与审核状态。
8. 第1章通过后发布第2、3章，再次核对没有重复、截断或错书。
9. 三章通过后才能继续后续章节；每次从 `.publish-state/` 和后台章节页双重确认断点。

脚本发现登录失效、页面结构变化、现有同章号/同标题、正文回读不一致、AI声明无法验证或确认按钮不可用时，会直接停止。
